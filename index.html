🎯 1. การเก็บข้อมูลอัตโนมัติ (ไม่ต้องตั้งชื่อและตั้งค่าใหม่ๆ)

ระบบมีระบบ Zero-Config Auto-Save เชื่อมต่อกับ SQLite 3 ในเครื่องของคุณโดยตรง:

  • ทุกครั้งที่คุณพิมพ์ชื่อเคส, กรอกลายน้ำ, เลือกคำเตือน, ปรับสัดส่วน 1:1 หรือ 4:5, และตั้งค่าเซ็นเซอร์ปิดตา ข้อมูลจะถูกบันทึกลงตาราง app_state ใน SQLite ทันที
  • เมื่อเปิดหน้าเว็บมาใหม่หรือรีเฟรช: ข้อมูลล่าสุดที่คุณเคยทำไว้จะถูกดึงกลับมาแสดงผลอัตโนมัติ 100% โดยไม่ต้องคอยพิมพ์ใหม่ และไม่ต้องเสียเวลาตั้งชื่อพรีเซ็ตใหม่
  • หากต้องการบันทึกเป็นชุดค่าเริ่มต้นสำหรับคลินิก สามารถกดปุ่ม ⭐ บันทึกเป็นค่าเริ่มต้น ได้ทันที

🚪 2. วิธีเข้าสู่ฐานข้อมูล SQLite

คุณสามารถกดเปิดหน้าต่างจัดการฐานข้อมูล SQLite นี้ได้จากหลายจุด:

  • Desktop: ปุ่ม 🗄️ SQLite ที่แถบเมนูหัวเว็บด้านบนขวา (ข้างปุ่มภาษา) หรือปุ่ม 🗄️ ฐานข้อมูล SQLite ในแผงพรีเซ็ต
  • Mobile: แตะที่แท็บ 🗄️ SQLite บนแถบเมนูนำทางเลื่อนได้ (Category Pill Tabs)

💻 3. วิธีเปิดดูและนำไฟล์ SQLite ไปใช้งานบนคอมพิวเตอร์

ไฟล์ฐานข้อมูลเป็นมาตรฐาน SQLite 3 จริง 100% (.sqlite / .db):

  • กดปุ่ม 💾 ดาวน์โหลด presets.sqlite ด้านล่าง เพื่อเซฟไฟล์ฐานข้อมูลลงเครื่องคอมพิวเตอร์
  • สามารถเปิดไฟล์ได้ด้วยโปรแกรมฟรี เช่น DB Browser for SQLite (sqlitebrowser.org), DBeaver หรือเปิดดูบนเว็บได้ทันทีที่ sqliteonline.com
  • คุณจะเห็นตาราง presets (พรีเซ็ตทั้งหมด), clinic_settings (โลโก้คลินิก), และ app_state (สถานะล่าสุด)

🔄 4. วิธีย้ายข้อมูลข้ามเครื่อง (Backup & Restore)

ต้องการนำพรีเซ็ตและการตั้งค่าไปใช้บนคอมพิวเตอร์เครื่องอื่นหรือมือถือ:

  • กดปุ่ม 💾 ดาวน์โหลด presets.sqlite จากเครื่องเดิม แล้วส่งไฟล์ทาง LINE / Email / AirDrop
  • เปิดเว็บนี้บนเครื่องใหม่ แล้วกดปุ่ม 📥 นำเข้าไฟล์ .sqlite แล้วเลือกไฟล์ดังกล่าว
  • ข้อมูลทั้งหมดจะถูกกู้คืนและซิงค์ทันทีโดยไม่ต้องตั้งค่าใหม่
